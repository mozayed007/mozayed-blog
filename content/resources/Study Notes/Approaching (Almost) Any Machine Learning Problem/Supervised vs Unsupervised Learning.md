- Mainly in realm of Machine Learning there're generally 2 types of data/models.
	- Supervised data: Has one or many labels/targets associated with its features.
	- Unsupervised data: Doesn't have any labels/target variables.
- Supervised problems are usually easier to tackle than an unsupervised one where the goal's to predict a specific target/label/value.
- In Supervised problems, if the target/label/value is categorical or encoded numerical it can be treated as a classification problem. However, if the target/label/value is a real number it can be defined as a regression problem.
	- Classification: predicting a category/label.
	- Regression: predicting a numerical value.
- Unsupervised problems has no labels/target associated with the data.
- In addition, we use numerous decomposition techniques to get an intuition behind some unsupervised problems.
	- Known as Dimensionality Reduction Techniques: ( You can check StatQuest, Orange Data mining YT channels for their explanations)
		- Principal Component Analysis (PCA).
		- Multi-Dimensional Scaling (MDS).
		- t-Distributed Stochastic Neighbor Embedding (t-SNE).
- In Evaluation stages supervised problems can be tackled easier than unsupervised ones.
